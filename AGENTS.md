# Agriterra — Agritech em Angola

Plataforma integrada de alertas SMS climáticos para agricultores sem internet e logística directa da lavra ao supermercado.

## Stack Técnica
- React.js (JavaScript + JSX)
- Vite
- Tailwind CSS v4
- React Router DOM
- Leaflet / React-Leaflet
- TanStack Query
- Lucide React & Recharts
- Supabase
